## 🚀 Featured Projects

### 📰 [Arabic News Analyzer](https://github.com/Shahdali812004/news-analyzer)

**Qwen2.5-1.5B • LoRA • Knowledge Distillation • vLLM • FastAPI • Streamlit • LLaMA-Factory**

An end-to-end Arabic NLP platform for **structured news analysis and multilingual translation**.

The core idea was to **mimic GPT-4o-mini's performance with a much smaller model**, making the system practical to run with limited computational resources.

### What I built

* Fine-tuned **Qwen2.5-1.5B-Instruct** using LoRA
* Used **GPT-4o-mini as a teacher model** to generate high-quality synthetic training data
* Applied knowledge distillation to transfer task-specific behavior to the smaller model
* Built structured JSON generation with **Pydantic**
* Deployed the model using **vLLM**
* Implemented dynamic LoRA adapter loading
* Built a **FastAPI REST API**
* Built an interactive **Streamlit dashboard**
* Tracked experiments with **Weights & Biases**
* Load-tested the API with **Locust**

### Engineering results

* ⚡ ~**25× higher inference throughput** with vLLM compared with standard Transformers inference
* ⏱️ ~15-second latency on 3,800-token contexts
* 🧪 Tested with 20 concurrent users
